# code of conduct

Short version: be useful, be accurate, be civil.

## expected behaviour

- Criticize the text, not the person who wrote it.
- Say what is wrong and what would be right instead.
- Assume the other person knows something you do not.
- Ask a question before assuming bad intent.
- Explain jargon when someone new is reading.

## unacceptable behaviour

- Personal attacks, harassment, or demeaning remarks of any kind.
- Discrimination based on nationality, gender, background, religion, age, or
  ability.
- Publishing private information about anyone.
- Deliberately posting false or unverifiable claims as fact.
- Sustained disruption of discussion.

## scope

This applies to issues, pull requests, commit messages, and any other space
where this repository is discussed.

## enforcement

Reports go to the repository owner through a private channel: open a GitHub
security advisory or email the address on the owner's GitHub profile. Reports
are handled privately.

Possible outcomes, depending on severity: a request to edit, deletion of the
content, or a block from the repository. There is no appeal process; this is a
personal notebook, not an institution.

## attribution

The spirit follows the widely used
[Contributor Covenant](https://www.contributor-covenant.org), trimmed to what
one maintainer can actually enforce.
